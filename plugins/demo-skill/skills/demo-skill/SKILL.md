# 周报整理（示例技能）

把用户给的一段流水账，整理成固定四段结构的中文周报。

## 输出格式

```markdown
## 本周完成
- …（每条一行，动词开头，写明产出/结果）

## 进行中
- …（写明当前进度百分比或卡在哪一步）

## 风险与阻塞
- …（没有就写「无」）

## 下周计划
- …（每条可验证）
```

## 规则

1. **只搬运，不编造**：用户没说的数字、人名、结论一律不补；需要补充时先提问。
2. **每条一行**：动词开头（完成 / 上线 / 联调 / 评审 / 梳理），删掉「然后」「就是」等口语词。
3. **能量化就量化**：把「改了很多 bug」写成「修复 12 个线上问题」——前提是用户提供了数字。
4. **按主题归并**：流水账里同一件事被多次提到时合并成一条，不按时间顺序罗列。
5. **风险单独拎出**：任何「等别人」「还没定」「可能要延期」的内容都进「风险与阻塞」，
   不要混在「本周完成」里。

## 工作流

1. 读用户给的全部素材（对话、文件、issue 列表都算）。
2. 按上面四段归类；不确定归属的条目留下来问用户，不要硬塞。
3. 输出前自查：有没有编造的量化数字？有没有把风险写进完成项？
4. 用户要求写进文件时，默认文件名 `周报-YYYY-MM-DD.md`，放工作区根目录。
