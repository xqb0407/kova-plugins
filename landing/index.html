02 — 目录

六个正式插件，
各管一段工作流。

共同点只有一条：都能和 agent 读写同一份工作区文件。 装完刷新市场就生效，不用重启。

  1. 01

    canvas 技能 + 面板

    Excalidraw 式无限空间：文本、形状、图片、Mermaid、表格、图表、网页嵌入自由摆放，整张画布导出 SVG。文档是 *.canvas.json。

    whiteboarddiagram
  2. 02

    office 技能 + 面板 + MCP

    幻灯片逐页编辑、放映、导出 pptx / pdf / svg / html；Univer 表格带公式、样式、冻结；文档保留标题层级与行内样式。

    pptxxlsxuniver
  3. 03

    ui-design 技能 + 面板 + MCP

    页面、画板、图层树与完整属性检视（填充、渐变、描边、圆角、阴影、文字）。独立 *.uidesign.json，agent 可直接增删改节点、对齐、堆叠、成组。

    figmaprototype
  4. 04

    gitlab 技能 + MCP

    项目检索、issue 与评论、MR 详情与 diff、审批、CI 流水线与作业日志。评论写入走预览 + confirmToken 两段确认，token 只从用户配置或 macOS 钥匙串读。

    merge-requestci
  5. 05

    rea 技能 + MCP

    Mach-O / PE / ELF 静态分析：段表与熵、导入导出与可疑 API、字符串与 IOC、字节搜索、分块熵图、objdump 反汇编。只读，不执行样本。

    reverseioc
  6. 06

    phone 技能 + MCP

    通过 ADB 操作真机与模拟器：截图、uiautomator 控件树、点击滑动、滚动查找、ADBKeyboard 中英文输入、启动应用、等待界面变化。每个动作可带 observe 一步取回新界面。

    androidadbqa
清单另有 demo-skill 与 demo-panel 两条最小示例，用于对照格式，可直接删。 marketplace.json

03 — 交付形态

能力只有三种装法。

技能教 agent 怎么做，面板给人一间能动手的房间，MCP 让 agent 伸手到外面。三者可以叠在同一个插件里。

01 / SKILL

技能

一份 SKILL.md，写清触发场景与操作步骤。装进系统提示词目录，模型按 description 判断何时加载。

skills/frontmatter按需加载
02 / PANEL

面板

自包含单文件 HTML，挂进沙箱 iframe。走 kova-ui-plugin/1 桥读写工作区文档；重面板可用 React + Vite 构建后把产物入库。

panels.jsonpostMessage*.json
03 / MCP

工具

手写 stdio JSON-RPC，由宿主内建运行时拉起。经 mcp 网关搜索、描述、调用，权限逐次受控。

.mcp.jsonstdio按次授权

04 — 安装

三步，从克隆到能用。

目录市场适合本地开发，改完文件不用重装；推到远端后可以换成 git 市场，队里共用同一份清单。

01

添加市场

插件页 → 添加市场，类型选「目录」，填本仓库的绝对路径。

~/Desktop/kova-plugins
02

安装插件

在市场列表里挑插件，安装方式选「链接安装 · 开发」。缓存是指向源码的符号链接，改完文件即时生效。

清单改动后刷新市场或重装一次；面板 HTML 与 SKILL.md 改动重开面板、新开会话即生效。
03

开始用

新会话里触发技能，或让 agent 写到 .canvas.json、.deck.canvas.json，面板会自动打开并绑定该文档。

推送到远端后改用 git 市场，更新流程是 commit → push → 刷新市场 → 点更新。

05 — 开发

写一个插件，
从清单开始。

目录名必须与 name 完全一致，声明你交付哪些组件， 在根部 marketplace.json 加一条，刷新市场就看得见。 发布前跑一次自检脚本，它会核对清单一致性、组件路径与面板的外部资源引用。

对照现有实现 →
plugins/my-plugin/.kova-plugin/plugin.json
// 清单：声明你交付什么
{
  "name": "my-plugin",
  "version": "0.1.0",
  "description": "一句话说明",
  "skills": "skills",
  "panels": "panels.json",
  "mcpServers": ".mcp.json"
}

// 自检
$ node scripts/check.mjs
